首个可自签的「阅间」原生 iPhone / iPad 客户端预发布版本，要求 iOS / iPadOS 16 及以上。

- 登录时填写自己的 reader-rust 服务器地址，不内置私人服务器地址。
- 原生书架、文字阅读、目录、字号 / 行距 / 主题及章节缓存；书源管理和搜索加书暂通过现有网页完成。
- 网页与 App 使用同一服务器、同一账号同步章节和章节内进度，并处理两端同时阅读产生的冲突。

下载 `Reader-unsigned.ipa` 后，需要使用自己的 Apple ID 或证书进行签名安装；不是直接安装包或 TestFlight 包。附有 SHA-256 校验文件。

同步需要 NAS 后端与网页一并更新到本版本源码中的实现（含 `POST /reader3/syncBookProgress`），仅安装 IPA 不会更新 NAS 服务。

本次按用户要求停止云端模拟器补测，仅编译和打包。原生完整 UI 流程、用户 NAS 联调及自签真机体验尚未完成验收，因此标记为预发布版本。
